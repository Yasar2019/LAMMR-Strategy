## Configuration

```powershell
# Edit strategy parameters
notepad config.yaml

# Or with VS Code
code config.yaml
```

**Key parameters:**
- `zscore_buy_threshold: -1.5` (Oversold signal)
- `zscore_sell_threshold: 1.5` (Overbought signal)
- `position_size_pct: 0.02` (Risk 2% per trade)
- `max_drawdown_pct: 15.0` (Stop trading if DD > 15%)
- `slippage_bps: 1` (1 basis point)
- `commission_bps: 1` (1 basis point)

## Key Metrics

- **Sharpe Ratio**: Risk-adjusted returns (higher = better)
- **Win Rate**: % of profitable trades
- **Max Drawdown**: Worst underwater % from peak
- **Profit Factor**: Gross wins / Gross losses
- **IC**: Information Coefficient (signal quality)

---

## Strategy Logic (Deterministic)

```python
if z_score < -1.5 and liquidity > 0.65:
    signal = 'BUY'      # Oversold + liquid
elif z_score > 1.5 and liquidity > 0.65:
    signal = 'SELL'     # Overbought + liquid
elif abs(z_score) < 0.3:
    signal = 'EXIT'     # Mean reversion
else:
    signal = 'HOLD'     # No signal
```

Position size: `shares = (account * 2%) / entry_price`
